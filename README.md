# 求职风向 Agent

校招前期的 **Market-first** 求职风向助手：先听你的意愿方向，再用市场岗位信号回答「市场要什么、竞争与供给如何、该如何准备」。

个人背景只作约束过滤，不做专业/简历匹配主引擎，也不做海投、ATS 改简历或投递流水线。

## 产品定位

| 维度 | 说明 |
|------|------|
| 目标用户 | 大学生校招（定方向 / 调方向 / 前期准备） |
| 服务阶段 | 投递前；不覆盖中后段执行 |
| 驱动方式 | 市场行情与岗位信号优先，而非「已有能力匹配岗位」 |
| 人在回路 | 结论可解释、可反馈重算；人做最终决定 |

## 核心价值

- **感知风向**：从岗位样本看技能/专业词频、分城供给、应届薪资区间等可核对信号  
- **可解释结论**：关键判断挂靠报告模块（如「依据第 N 部分」），避免黑箱「推荐某司」  
- **前期准备路线**：按初 / 中 / 高阶段给出能力准备计划  
- **先算后说**：量化指标由代码统计；大模型只解读 Evidence Pack，不编造数字  

## 报告模块

1. **核心结论** — 风向判断与依据说明  
2. **细分岗位与职责** — 方向下典型子岗职责概括  
3. **核心能力与专业要求** — 基于岗位详情库的技能 / 专业词频  
4. **分城岗位供给** — 相对星级与综合难度参考  
5. **预期薪资范围** — 应届 / 低年限档分位与均数（箱线示意）  
6. **求职风向** — 基于在线岗位样本的综合分析（样本不足时不展示）  
7. **能力准备计划** — 初 / 中 / 高三阶段行动项  
8. **人在回路** — 「这份报告哪里不对」：驳回结论、排除岗位、加对比城市、追问重算  

## 主链路（概念）

```text
用户意愿方向
  → 取数与指标计算（详情库 / 薪资库 / 可选在线浅采）
  → Evidence Pack（结构化证据，数字只来自代码）
  → 大模型解读（职责 · 准备计划 · 结论 · 风向文案）
  → HTML 风向报告（可 HITL 局部重算）
```

## 明确非目标

- 全自动批量投递、申请管道  
- ATS 简历优化红海工具  
- 测评式人岗匹配或兴趣技能图谱主推荐  
- 模拟面试 / 中后段流程编排  

## 技术要点（摘要）

- Web Demo：FastAPI + Jinja2 报告页  
- 编排：工具型流水线（指标计算与生成解耦）  
- 模型侧：阿里云百炼 / DashScope（如 `qwen-plus`）只读 Pack 写自然语言  
- 数据：岗位详情快照 + 薪资快照；在线模块为浅层补充信号
